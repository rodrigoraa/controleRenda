# Uso prioritário no celular

Objetivo: facilitar o controle diário pelo celular preservando os fluxos financeiros e o acesso pelo computador.

Implementação: navegação inferior com inclusão rápida; lançamentos apresentados em cartões sem rolagem lateral; texto e alvos de toque maiores; formulários em painel adaptado ao teclado, com ações sempre acessíveis; suporte a áreas seguras da tela e atalhos para recorrências e conta. A adaptação usa a interface React existente, sem instalar app nativo ou armazenar dados financeiros offline.
